# drivematch

DriveMatch is a cutting-edge web application designed to search the used car market for vehicles that match user-defined criteria. Leveraging advanced web scraping techniques and data analysis, DriveMatch provides users with a seamless experience to find their ideal used car.

## Roadmap

- embed web scraper
- add list and get cli command
- unique vehicle detection
- add custom attributes to vehicle model
- define http api schema
- write http api server
- write web frontend in vue
